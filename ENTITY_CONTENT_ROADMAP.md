# Entity Content Roadmap

This roadmap translates the format entity database and gap report into a practical content plan for entity pages, supporting articles, converter explainers, FAQ coverage, schema enrichment, and learning-center linking.

## Objective

Build a content system that supports:
- high-intent search queries around file formats and conversion tasks
- strong internal linking from entities to converters and learning content
- better schema opportunities for entity pages
- faster publisher output for the highest-value formats first

## Priority Framework

Priority selection is based on a mix of:
- missing format page coverage
- missing learning page coverage
- strong conversion demand from the current converter inventory
- high search intent for common file formats
- strong potential for FAQ and AI Overview expansion

## Priority B and C Execution Notes

### Priority B formats
Focus on expansion content that strengthens supporting relationships and converter explainers:
- AVIF, FLAC, MP3, OGG, WEBP, SVG, TIFF, and office spreadsheet formats should receive article clusters and comparative content.
- These should be built after the Priority A entity pages are live, using the same schema and internal-link pattern.

### Priority C formats
Use these as lower-urgency augmentation targets:
- AAC, BMP, GIF, ICO, ODP, RTF, TXT, and XLS should receive lighter content bundles focused on FAQ coverage and relationship support rather than full-scale entity expansion.

---

## Recommended Publishing Order

1. Create the core missing entity pages for 7Z, GZ, GZIP, JPEG, JPG, MP4, ZIP, RAR, and TAR.
2. Publish the high-intent document and spreadsheet entities for PDF, DOCX, and XLSX.
3. Expand image entities for PNG and WebP with comparative and optimization content.
4. Add secondary supporting articles for AVIF, FLAC, MP3, SVG, TIFF, and OGG.
5. Finish the lower-urgency office and legacy-format content bundles.

---

- one primary entity page
