## Scope
The homepage is considered approved and frozen.

- Header

- Floating Icons
- Homepage Typography
- Homepage Layout

- Do not refactor Homepage.

- Do not improve Homepage.
- Do not redesign Homepage.
- Do not change spacing.
- Do not change typography.
- Do not move upload card.

- Do not change background.

## Allowed Changes Only
Only the following changes are allowed:
- Critical bug fixes
- Security fixes
- Accessibility fixes
- Explicitly approved changes

## Future Change Policy
Any future task that requires Homepage changes must stop and request approval first.
